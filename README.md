## About the Project

StyleSurfer is a full-stack fashion rental platform offering an affordable and sustainable alternative to conventional fashion consumption.
The system integrates rental services, reselling options, customization workflows, and flexible rental durations along with a multi-role operational structure.

It supports Customers, Sellers, Delivery Partners, and Admins through dedicated dashboards and a unified backend.

### Patent Status

The innovation behind this project is officially published as an **Indian Patent** under:

* Title: **Automated Clothing Rental Kiosk**
* Patent Application Number: **202521070250 A**
* Filing Date: 23/07/2025
* Publication Date: 08/08/2025
* Published in: *The Patent Office Journal, Issue 32/2025*
* Institution: **Marwadi University**

## Key Features and System Highlights

* Flexible rental periods without predefined restrictions
* Resell listings for used or over-cycled garments
* Buy-back and personalization workflows
* Gamified spin-to-win reward mechanism
* Multi-role dashboards for all user types
* Email-based OTP authentication
* Cart, checkout, order tracking, and transaction-ready system
* Fully responsive, modern UI
* Enterprise-style functional architecture
