## 👗 Features

- <b style="color:#8d6748;">Outfit Rentals:</b> Browse, filter, and rent stylish, high-quality clothes.
- <b style="color:#8d6748;">Buy Back Option:</b> Customize and return outfits within a set duration.
- <b style="color:#8d6748;">Reselling:</b> Purchase pre-rented outfits at discounted rates.
- <b style="color:#8d6748;">Spin-to-Win Discounts:</b> Gamified experience for extra savings.
- <b style="color:#8d6748;">Seller Dashboard:</b> List/manage products, track sales, and receive payments.
- <b style="color:#8d6748;">Delivery Partner Tools:</b> Automated order assignments and navigation support.
- <b style="color:#8d6748;">User Profiles:</b> Easy sign-up, profile management, and rental history.
- <b style="color:#8d6748;">Sustainability Focus:</b> Promotes reuse and reduces fashion waste.
