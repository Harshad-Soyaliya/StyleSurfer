## About the Project

StyleSurfer is a full-stack fashion rental platform offering an affordable and sustainable alternative to traditional garment usage.
The system integrates rental services, reselling options, customization workflows, flexible rental durations, and multi-role dashboards.

### Patent Publication

This project has been officially published as an Indian Patent:

**Automated Clothing Rental Kiosk**
Patent Application No: **202521070250 A**
Filing Date: 23/07/2025
Publication Date: 08/08/2025
Published in The Patent Office Journal No. 32/2025
Submitted under Marwadi University

## Key Features and System Highlights

* Flexible rental durations without fixed constraints
* Built-in resell marketplace for pre-used garments
* Buy-back and personalization workflows
* Spin-to-win reward system
* Multi-role dashboards for customers, sellers, delivery partners, and admin
* Email OTP authentication
* Cart, checkout, payment-ready flow, and order tracking
* Fully responsive, modern UI
* Robust backend with enterprise-like architecture
